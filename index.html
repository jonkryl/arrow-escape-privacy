1. Игровой прогресс

Игра сохраняет на устройстве номер уровня, удалённые стрелки, жизни, подсказки, ошибки и настройки рекламы и вибрации. Это нужно для продолжения игры и сохранения выбранных настроек.

Прогресс не отправляется на сервер разработчика. У приложения нет учётных записей и собственного сервера для хранения игровых данных. Сохранение остаётся на устройстве до очистки данных приложения или его удаления.

2. Реклама и данные SDK

Для рекламы РСЯ используется Yandex Mobile Ads SDK 8.5.0: баннер, объявления между уровнями и добровольное видео за подсказку или жизнь.

При рекламных запросах SDK может обрабатывать рекламный и другие идентификаторы устройства, IP-адрес, технические сведения об устройстве и приложении, параметры запросов, показов и взаимодействий с объявлениями. Эти данные используются для показа и подбора рекламы и оценки её эффективности.

Рекламные данные передаются Яндексу через SDK. Яндекс и его рекламные партнёры обрабатывают их по политике https://yandex.com/legal/confidential/ , включая описанные там передачу данных между странами, сроки хранения и права пользователей. Практика SDK: https://ads.yandex.com/helpcenter/en/dev/android/app-privacy-android .

Игра не запрашивает разрешений на геолокацию; её передача SDK отключена. Приложение не запрашивает имя, телефон, email или платёжные данные.

3. Выбор рекламы

Перед первой инициализацией SDK можно выбрать рекламу с персонализацией или без неё. Сохранённый выбор передаётся SDK при каждом запуске. Изменить его можно в меню «Реклама и конфиденциальность». Рекламным идентификатором также можно управлять в настройках Android.

Выбор «Без персонализации» передаёт SDK отсутствие согласия на персонализацию. Технические запросы для показа рекламы могут продолжаться. Видео за награду запускается только по нажатию пользователя. Игра доступна без сети; для загрузки рекламы нужен интернет.

4. Защита и хранение

Прогресс хранится в локальных данных приложения. По документации Яндекса, передаваемые Mobile Ads SDK данные защищаются с помощью HTTPS/TLS.

Яндекс хранит рекламные данные в течение времени, необходимого для целей обработки или выполнения требований закона, согласно своей политике. SamokrylTeam не хранит копии игрового прогресса и рекламных идентификаторов на собственном сервере.

5. Удаление и обращения

Чтобы удалить локальные уровни, игровые показатели и настройки, очистите данные приложения в настройках Android или удалите приложение.

По вопросам данных, доступа, исправления, удаления или отзыва согласия пишите SamokrylTeam: jonkryl@gmail.com. Если вы обращаетесь по email, адрес отправителя и содержание письма используются для рассмотрения запроса; переписка хранится столько, сколько нужно для ответа и выполнения применимых требований закона.

Запросы о данных, обрабатываемых Яндексом, также можно направить через контакты и механизмы из его политики: https://yandex.com/legal/confidential/ .

6. Обновления

При изменении обработки данных мы обновляем эту политику и дату редакции. Актуальная версия доступна в приложении и по адресу https://jonkryl.github.io/arrow-escape-privacy/ .
